# memos stack

## Files

- `compose.yaml`: compose definition used by `apps/deploy/ansible/playbooks/deploy-memos.yml`
- `.env.example`: repo-safe defaults

## Runtime config/secrets pattern

- repo baseline: `apps/stacks/memos/.env.example`
- NAS override (optional): `{{ nas_config_app_env_dir }}/memos.env`
- runtime file generated by Ansible: `/data/stacks/memos/.env`

## Exposure model

- Memos is routed through Traefik on the shared `proxy` Docker network.
- The canonical healthcheck path is the proxied route with `Host: {{ memos_hostname }}`.
