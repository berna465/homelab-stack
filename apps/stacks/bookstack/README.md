# bookstack stack

## Files

- `compose.yaml`: compose definition used by `apps/deploy/ansible/playbooks/deploy-bookstack.yml`
- `.env.example`: repo-safe defaults

## Runtime config/secrets pattern

- repo baseline: `apps/stacks/bookstack/.env.example`
- NAS override (optional): `{{ nas_config_app_env_dir }}/bookstack.env`
- runtime file generated by Ansible: `/data/stacks/bookstack/.env`

## Exposure model

- BookStack is exposed through the shared Traefik reverse proxy on the `proxy` network
- MariaDB remains internal to the stack and is not published on the host
