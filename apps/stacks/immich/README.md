# immich stack

## Files

- `compose.yaml`: compose definition used by `apps/deploy/ansible/playbooks/deploy-immich.yml`
- `.env.example`: repo-safe defaults compatible with current deploy flow

## Runtime config/secrets pattern

- repo baseline: `apps/stacks/immich/.env.example`
- NAS override (optional): `{{ nas_config_app_env_dir }}/immich.env`
- runtime file generated by Ansible: `/data/stacks/immich/.env`

Where supported, prefer `*_FILE` or Docker secrets for sensitive values; keep `.env` fallback for compatibility.


## Canonical content path

- Canonical: `/mnt/nas/data/apps/immich/library`
- Legacy compatibility fallback: `/mnt/nas/data/apps/immich/upload`
