# jellyfin stack

## Files

- `compose.yaml`: compose definition used by `apps/deploy/ansible/playbooks/deploy-jellyfin.yml`
- `.env.example`: repo-safe defaults

## Runtime config/secrets pattern

- repo baseline: `apps/stacks/jellyfin/.env.example`
- NAS override (optional): `{{ nas_config_app_env_dir }}/jellyfin.env`
- runtime file generated by Ansible: `/data/stacks/jellyfin/.env`
