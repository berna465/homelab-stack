# memos stack

## Files

- `compose.yaml`: compose definition used by `playbooks/deploy-memos.yml`
- `.env.example`: repo-safe defaults

## Runtime config/secrets pattern

- repo baseline: `stacks/memos/.env.example`
- NAS override (optional): `{{ nas_config_app_env_dir }}/memos.env`
- runtime file generated by Ansible: `/data/stacks/memos/.env`
