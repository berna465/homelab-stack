# journiv stack

## Files

- `compose.yaml`: compose definition used by `playbooks/deploy-journiv.yml`
- `.env.example`: repo-safe defaults

## Runtime config/secrets pattern

- repo baseline: `stacks/journiv/.env.example`
- NAS override (optional): `{{ nas_config_app_env_dir }}/journiv.env`
- runtime file generated by Ansible: `/data/stacks/journiv/.env`
